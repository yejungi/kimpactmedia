# K-IMPACT Media Group — Corporate Showroom Final

This package is a full static replacement for the **corporate introduction/showroom site**, not the future K-Beauty newsroom.

## What this version intentionally preserves from the existing site
- Large, premium corporate-page volume and visual presence
- Leadership / Founder prominence
- Portfolio architecture
- K-Beauty as the first vertical
- Future K-Food / K-Wellness / K-Fashion vision, clearly labeled as future verticals
- Responsibility / ESG principles
- Partnership section
- Contact form UI
- Blog / Instagram routes
- Strong global-facing brand language

## What was intentionally removed or rewritten
- Unsupported brand scores and ranking numbers
- Blind-Spot scores
- Fake/preview "real-time" trend metrics
- Claims of an operating AI prediction engine
- Claims of an operating Product Database / Deals Engine / Creator tracking system
- Concrete donation percentages and NGO integrations that are not operating
- Self-promotional newsroom cards presented as if they were established external coverage
- Claims that unlaunched verticals are operating products

## Core brand language
- Korea, decoded.
- Beyond headlines.
- We don't just report what happened. We explain why it matters.
- A newsroom instinct. A founder's ambition.
- Build with us.
- Beauty, as an industry.

## Deployment
Upload the CONTENTS of this folder to the root of the repository serving `kimpactmedia.com`.

**Do not delete deployment-specific files such as `CNAME` or `.github/` unless you know they are no longer needed.**
If a `CNAME` file exists in the current GitHub repository, preserve it when replacing the website files.

## Contact
The site currently uses the known working address `yejungi@naver.com`.
Replace it with `contact@kimpactmedia.com` only after that domain address has actually been configured to receive/forward mail.

## Founder image
This package uses an intentionally designed LY visual block rather than inventing or bundling an unverified photo asset.
If you want the current real Founder photo retained, add the authorized image as `assets/founder.jpg` and update the Founder visual block after deployment.

## Search
Includes canonical URLs, Open Graph metadata, JSON-LD, robots.txt and sitemap.xml. These support crawling and understanding; they do not guarantee search indexing or ranking.
